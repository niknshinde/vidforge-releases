# VidForge

VidForge is a desktop video editor with AI-assisted editing. This repository hosts the Windows installers and the auto-update feed (the source code is private).

## Download

**[Download VidForge for Windows](https://niknshinde.github.io/vidforge-releases/)**

The download page always links to the newest installer. You can also grab any version from the [Releases page](https://github.com/niknshinde/vidforge-releases/releases/latest).

## Install

1. Download `VidForge-Setup-<version>.exe`.
2. Run it and choose an install folder. It installs for your user account only, so no administrator rights are needed.
3. If Windows SmartScreen shows a warning, click **More info**, then **Run anyway**.

## Updates

Once installed, VidForge checks this repository for new versions and offers to update itself.

## Requirements

- Windows 10 or 11, 64-bit
- About 1.5 GB of free disk space
